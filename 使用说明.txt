心阅小说 v4.1.3 · 全功能回归修复版
================================

本版重点修复：
1. 修复“项目 · 章节 → 导出完整 TXT”点击后出现：
   syscall: string with NUL passed to StringToUTF16
   的 Windows 保存对话框崩溃问题。
2. 保存对话框的文件类型过滤器改为专用 Win32 UTF-16 编码，不再把含 NUL 分隔符的字符串传给 syscall.StringToUTF16。
3. 导出文件名会自动替换 Windows 禁止字符（\\ / : * ? " < > |），中文书名正常保留。
4. 导出失败时会明确弹出实际错误，不再无条件显示“导出成功”。
5. 修复剪贴板打开失败仍继续执行的问题；复制失败会明确提示。
6. “停止”按钮在没有进行生成任务时保持禁用，任务结束后自动恢复禁用。
7. API 测试成功后，如果本机 Key 保存失败，会明确提示，不再误报“已保存”。
8. 切换小说项目时清空上一个项目的临时“本章特殊要求 / 续写上下文”，防止不同小说之间串上下文。
9. 项目名称、历史设定、世界观、境界、总纲、卷纲、人物、剧情、章节的 v4.1.2 数据修复逻辑继续保留。
10. “情感细腻风”、API Key 本地 DPAPI 加密保存、多项目、章节增删改、最近章节上下文、AI 大纲/境界等功能继续保留。

数据位置：
- 当前项目库：%LOCALAPPDATA%\XinyueNovel\LocalLibrary
- 设置/API Key：%LOCALAPPDATA%\XinyueNovel\settings.json
- 启动日志：%LOCALAPPDATA%\XinyueNovel\Logs\startup.log

API Key：
- 首次在“设置”页输入并测试成功后，会使用 Windows DPAPI 加密保存在本机。
- 以后启动会自动读取，不需要每次重新输入。
- API Key 不会写进小说项目 JSON、章节正文或导出的 TXT。

导出完整小说：
进入“项目 · 章节” → 选择项目 → 点击“导出完整 TXT” → 选择保存位置。
默认文件名为“小说名称_完整小说.txt”。
